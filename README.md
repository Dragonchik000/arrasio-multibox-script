# 🤖 LUL - Arras.io Multibox Bot Pro v3.2.1

**Продвинутый Tampermonkey скрипт для arras.io с Discord авторизацией, поддержкой прокси и полной автоматизацией**

⚠️ **ТОЛЬКО ДЛЯ САЙТА:** https://arras.io/

---

## ✨ Основные возможности

### 🎮 Автоматизация
- ✅ **Автоатака** - Автоматическое нападение на ближайших врагов
- ✅ **Автопилот** - Автоматическое собирание еды и передвижение
- ✅ **Автобилд** - Автоматический апгрейд навыков танка
- ✅ **Следование за мышкой** - Танк следует за указателем мыши

### 👥 Multibox режимы
- ✅ **HOST** - Основной танк, синхронизирует позицию для других
- ✅ **CLIENT** - Следует за хостом, помогает в бою
- ✅ **Синхронизация** - Реал-тайм синхронизация позиции между окнами

### 🌐 Сетевые функции
- ✅ **Discord авторизация** - Требуется авторизация через Discord
- ✅ **Поддержка прокси** - Встроенный менеджер прокси
- ✅ **Авторотация прокси** - Автоматическая ротация при разрыве соединения
- ✅ **Резервные прокси** - Возможность добавления резервных прокси

### 🔒 Безопасность
- ✅ **URL проверка** - Скрипт работает ТОЛЬКО на https://arras.io/
- ✅ **Токен кеширование** - Токены Discord сохраняются на 24 часа
- ✅ **Безопасное хранилище** - Данные хранятся в GM_getValue/GM_setValue

## 📦 Установка

### 1️⃣ Установить Tampermonkey

**Chrome/Brave/Edge:**
- Откройте https://chrome.google.com/webstore/detail/dhdgffkkebhmkfjojejmpbldmpobp55f
- Нажмите "Установить расширение"

**Firefox:**
- Откройте https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/
- Нажмите "Добавить в Firefox"

### 2️⃣ Установить скрипт LUL

**СПОСОБ 1: Самый простой (прямая ссылка)**
```
1. Откройте ссылку:
   https://raw.githubusercontent.com/Dragonchik000/arrasio-multibox-script/main/LUL.user.js

2. Tampermonkey автоматически предложит установить скрипт

3. Нажмите "Установить"

4. Готово! Откройте https://arras.io/
```

**СПОСОБ 2: Скопировать-вставить**
```
1. Откройте Tampermonkey Dashboard (значок на панели браузера)

2. Нажмите кнопку "+" (Создать новый скрипт)

3. Скопируйте весь текст из файла LUL.user.js

4. Вставьте в редактор и нажмите Ctrl+S

5. Откройте https://arras.io/
```

**СПОСОБ 3: Из архива**
```
1. Распакуйте LUL.zip

2. Откройте файл LUL.user.js текстовым редактором

3. Скопируйте весь текст

4. В Tampermonkey нажмите "+" и вставьте как в СПОСОБЕ 2
```

## 🎯 Как использовать

### Кнопки управления

| Кнопка | Горячая клавиша | Функция |
|--------|-----------------|---------|
| ⚔️ ATK | Ctrl+Alt+A | Автоатака вкл/выкл |
| 🧭 PLT | Ctrl+Alt+P | Автопилот вкл/выкл |
| 🏗️ BLD | Ctrl+Alt+B | Автобилд вкл/выкл |
| 🔗 SYC | Ctrl+Alt+S | Синхронизация вкл/выкл |
| 👑 HOST | Ctrl+Alt+H | Переключить Host/Client |
| 👣 FLLW | Ctrl+Alt+F | Следование за хостом |
| 🚪 EXIT | - | Выход из аккаунта |

### Multibox для 2+ окон

**Окно 1 (Хост):**
```
1. Нажмите кнопку 👑 HOST
2. Кнопка должна быть зелёная
3. Скрипт будет транслировать позицию
```

**Окна 2+ (Клиенты):**
```
1. Скрипт автоматически в режиме CLIENT
2. Нажмите кнопку 👣 FLLW
3. Кнопка должна быть зелёная
4. Откройте оба окна в одном браузере
5. Готово! Клиенты будут синхронизированы
```

**Активация функций:**
```
Нажимайте нужные кнопки:
⚔️ ATK - автоатака на врагов
🧭 PLT - автопилот (движение к еде)
🏗️ BLD - автоматический апгрейд
🔗 SYC - синхронизация позиций
```

### Как добавить свой прокси

Откройте скрипт в Tampermonkey и найдите строку 43-47:

```javascript
PRIMARY: {
    host: 'dc.de-pr.plainproxies.com',    // Замените на ваш прокси
    port: 1338,                            // Замените на ваш порт
    username: 'DC_B06Tf3XfXR-ttl-0',      // Замените на ваш логин
    password: 'FQ0s56phl8LSgtI'            // Замените на ваш пароль
}
```

### Как добавить резервные прокси

Найдите строку 48-49 и добавьте:

```javascript
BACKUPS: [
    {
        host: 'backup1.proxies.com',
        port: 8080,
        username: 'user1',
        password: 'pass1'
    },
    {
        host: 'backup2.proxies.com',
        port: 8080,
        username: 'user2',
        password: 'pass2'
    }
]
```

### Изменить параметры бота

Строки 55-69:

```javascript
ARRAS_CONFIG = {
    AUTO_ATTACK: true,           // Автоатака вкл/выкл
    AUTO_PILOT: true,            // Автопилот вкл/выкл
    AUTO_BUILD: true,            // Автобилд вкл/выкл
    FOLLOW_MOUSE: true,          // Следование за мышкой
    
    ATTACK_RANGE: 400,           // Дальность атаки (в пикселях)
    FOLLOW_DISTANCE: 150,        // Расстояние следования за мышкой
    HOST_FOLLOW_DISTANCE: 250    // Расстояние следования за хостом
}
```

## 🐛 Решение проблем

### ❌ Скрипт не загружается
```
✓ Проверьте, что Tampermonkey включён (значок на панели)
✓ Откройте консоль браузера (F12 → Console)
✓ Обновите страницу arras.io
✓ Проверьте, что вы на https://arras.io/ (ТОЛЬКО этот сайт!)
```

### ❌ Авторизация не работает
```
✓ Проверьте, что у вас есть аккаунт Discord
✓ Убедитесь, что Discord доступен в вашей стране
✓ Попробуйте отключить VPN
✓ Закройте и откройте окно авторизации заново
```

### ❌ Автоатака не работает
```
✓ Нажмите кнопку ⚔️ ATK (должна быть зелёная)
✓ Проверьте, есть ли враги рядом
✓ Увеличьте ATTACK_RANGE в конфиге
✓ Проверьте консоль на ошибки (F12)
```

### ❌ Прокси не подключается
```
✓ Проверьте корректность данных прокси
✓ Убедитесь, что прокси активен
✓ Отключите VPN если она включена
✓ Добавьте резервный прокси
✓ Проверьте логи в консоли (F12)
```

### ❌ Multibox не синхронизируется
```
✓ Откройте ОБА окна в одном браузере
✓ На основном танке: 👑 HOST (должна быть зелёная)
✓ На остальных: 👣 FLLW (должны быть зелёные)
✓ Оба окна должны быть https://arras.io/
✓ Убедитесь, что синхронизация включена: 🔗 SYC (зелёная)
```
