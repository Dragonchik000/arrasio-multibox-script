# 🤖 Arras.io Multibox Bot Pro v3.1

Продвинутый Tampermonkey скрипт для arras.io с поддержкой multibox, автоматизацией и прокси.

## ✨ Возможности

### 🎮 Основные функции
- **Автоатака** - Автоматическое нападение на ближайших врагов
- **Автопилот** - Автоматическое собирание еды и передвижение
- **Автобилд** - Автоматический апгрейд навыков танка
- **Следование за мышкой** - Танк следует за указателем мыши
- **Синхронизация с хостом** - Multibox режим (Host/Client)
- **Поддержка прокси** - Встроенный менеджер прокси

### 🌐 Прокси поддержка
- ✅ Поддержка Datacenter прокси
- ✅ Авторотация прокси при разрыве соединения
- ✅ Проверка соединения каждые 30 секунд
- ✅ Резервные прокси (добавьте свои)
- ✅ Статус прокси в UI панели

### 🎛️ Режимы
- **HOST** - Основной танк, передаёт позицию клиентам
- **CLIENT** - Следует за хостом, помогает в бою

## 📦 Быстрая установка

### 1. Установить Tampermonkey
- **Chrome/Brave/Edge:** [Tampermonkey](https://chrome.google.com/webstore/detail/dhdgffkkebhmkfjojejmpbldmpobp55f)
- **Firefox:** [Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)

### 2. Установить скрипт (3 способа)

**Способ 1: По ссылке (САМЫЙ ПРОСТОЙ)**
1. Откройте: https://raw.githubusercontent.com/Dragonchik000/arrasio-multibox-script/main/LUL.user.js
2. Tampermonkey автоматически предложит установить
3. Нажмите "Установить"

**Способ 2: Копировать-вставить**
1. Откройте Tampermonkey Dashboard (значок на панели)
2. Нажмите **+** (Создать новый скрипт)
3. Скопируйте содержимое файла `LUL.user.js`
4. Вставьте в редактор и сохраните (Ctrl+S)

**Способ 3: Из архива**
1. Распакуйте `LUL.zip`
2. Откройте `LUL.user.js` любым текстовым редактором
3. Скопируйте весь текст
4. Вставьте в Tampermonkey как в Способе 2

## 🚀 Использование за 30 секунд

1. Откройте https://arras.io
2. Дождитесь загрузки - вы увидите зелёную панель слева
3. Нажимайте кнопки:
   - ⚔️ ATK - автоатака
   - 🧭 PLT - автопилот
   - 🏗️ BLD - апгрейды
   - 👑 HOST - для multibox (хост)
   - 👣 FLLW - следование за хостом (клиент)
   - 🌐 PRXY - прокси

## 🐛 Если что-то не работает

**Скрипт не видно:**
- Проверьте, что Tampermonkey включён (значок на панели)
- Откройте https://arras.io и обновите страницу
- Откройте консоль (F12) и посмотрите на ошибки

**Автоатака не работает:**
- Нажмите кнопку ⚔️ ATK (должна быть зелёная)
- Проверьте, есть ли враги рядом
- Увеличьте ATTACK_RANGE в конфиге скрипта

**Прокси не подключается:**
- Проверьте корректность данных
- Убедитесь, что прокси активен
- Отключите VPN если она включена

**Multibox не синхронизируется:**
- Откройте ОБА окна в одном браузере
- На основном танке: 👑 HOST (зелёная)
- На остальных: 👣 FLLW (зелёная)
- Оба окна должны быть https://arras.io
